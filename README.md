# Практическая работа 2. Поиск в Википедии

Консольное приложение для поиска статей в Википедии и открытия их в браузере.

## Стек технологий
* Java 11+
* Gson (для парсинга JSON)
* Wikipedia API

## Как запустить
1. Склонируйте репозиторий.
2. Убедитесь, что папка `lib` содержит файл `gson-2.10.1.jar`.
3. Откройте проект в IDE (например, VS Code или IntelliJ IDEA).
4. Запустите класс `Main.java`.

*Примечание: при работе в Windows может потребоваться настройка кодировки консоли на UTF-8 (например, с помощью `chcp 65001`).*
